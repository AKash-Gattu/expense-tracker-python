# Expense Tracker

## Description

A simple console-based expense management system developed using Python.

## Features

- Add Expense
- View Expenses
- Calculate Total Expenses
- Search Expenses by Category
- Exit the application

## Technologies Used

- Python

## Concepts Used

- Variables and Data Types
- Conditional Statements
- Loops
- Functions
- Lists
- Dictionaries
- User Input
- Basic Calculations

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run the following command:

```bash
python expense_tracker.py
